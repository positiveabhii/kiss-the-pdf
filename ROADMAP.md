# Roadmap

This project is being built in phases to ensure a solid foundation before adding complex PDF processing logic.

## Phase 1 — Foundation (Done)

*   [x] Next.js application setup
*   [x] Responsive application shell
*   [x] Expandable/collapsible sidebar
*   [x] Mobile navigation drawer
*   [x] Tool registry configuration
*   [x] Tool routing foundation
*   [x] First PDF tool

## Phase 2 — Core PDF Tools (Done)

*   [x] Merge PDF
*   [x] Split PDF
*   [x] Compress PDF
*   [x] Rotate PDF
*   [x] Extract Pages
*   [x] Delete Pages
*   [x] Reorder Pages

## Phase 3 — Conversion (Done)

*   [x] PDF → JPG
*   [x] JPG → PDF
*   [x] PDF → PNG
*   [x] PNG → PDF
*   [x] PDF → WebP
*   [x] PDF → TXT

## Phase 4 — Advanced PDF (Done)

*   [x] Watermark
*   [x] Add Page Numbers
*   [x] Crop PDF
*   [x] Edit Metadata
*   [x] Repair PDF
*   [x] Compare PDFs (free text diff, plus AI comparison with your own key)
*   [x] Redaction (true redaction: marked pages are flattened, metadata removed)

## Phase 5 — 100+ Tools (In progress)

*   [x] 100+ browser-based tools across organization, pages, conversion, editing, forms, security, enhancement and reading
*   [x] AI tools with your own API key (Claude, ChatGPT, Gemini): chat, summarize, search, compare
*   [ ] OCR for scanned PDFs
*   [ ] Document conversions (Word/Excel if feasible client-side)
*   [ ] More image tools and general file utilities
